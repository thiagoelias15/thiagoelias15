## 🚀 Proyectos destacados

### ️Plug & Pray - Proyecto final Sistemas Operativos (UTN FRBA, 2026)

* **Descripción:** Sistema distribuido en C que simula un SO con módulos independientes que se comunican mediante **sockets TCP** y servidores multihilo con semáforos para la planificación de procesos.

* **Aporte:** Me enfoqué en el ciclo de instrucción y proceso de traducción de direcciones, ambas funciones en el módulo de CPU. A su vez, me encargué de la revisión de código a lo largo del proyecto y de las pruebas tanto de comunicación como planificación entre módulos.

* **Tecnologías:** `C` `Sockets TCP` `Multithreading` `Semáforos` `Sistemas Operativos`

🔗 [Ver Repositorio](https://github.com/thiagoelias15/sisoputnfrba-tp-2026-1c-cin-panico.git)

* **Descripción:** Desarrollo en grupo de un videojuego de plataformas 2D en Wollok, en cuyo código se aplican principios del paradigma orientado a objetos.
